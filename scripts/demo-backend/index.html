🚀 Demo Backend Server

✅ Server is running!
This is a demo backend for testing SentinelGuard proxy functionality.

Available API Endpoints

GET /health

Health check endpoint - returns server status

GET /api/users

Returns a list of demo users

GET /api/status

Returns server status and request count

POST /api/auth/login

Authentication endpoint - accepts username/password

Request body:

{"username": "demo", "password": "password"}
PUT /*

Accepts any PUT request and returns success

DELETE /*

Accepts any DELETE request and returns success

Testing with curl

# Health check
curl http://localhost:8001/health

# Get users
curl http://localhost:8001/api/users

# Login
curl -X POST http://localhost:8001/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username": "demo", "password": "password"}'
